# Native single-photo editor

Added a minimal egui interface rendered through wgpu, with background RAW loading,
preview rendering, full-resolution export, and sidecar saves. Preview requests
coalesce; save/export requests are never discarded. Photo allocations are shared
with Arc. Generation checks reject stale previews and loaded-photo responses.
Failed opens preserve the current image and its original path.

The interface exposes the core editing modules, a histogram, curve editing,
clone/heal brush painting, undo/redo, comparison, fit/actual-pixel zoom, pan,
file dialogs, drag/drop, custom display ICC, and export color space. Unsaved edits
prompt before closing or replacing the photo. Slider drags form a single undo
gesture; clone strokes retain a source offset while painting. A compiled retouch
spatial index limits pixel work to nearby brushes, and heal offsets are computed
once per recipe.

Verified on X11 using the real GFX100S photo and a temporary copy under
`/tmp/rawpuppy-validation`. Inspected native-window screenshots on the workstation
and a separate 1440×960 Xvfb display. Changed exposure to +1 EV, saved with Ctrl S,
undid and saved to verify 0 EV, redid and saved to verify +1 EV, and reopened to
verify sidecar reload. Actual-pixel view renders directly from the sensor; a new
numerical test proves viewport pixels match a full-resolution render.

Fourteen core integration tests and strict Clippy pass. Added CI for Linux,
macOS, and Windows. Those jobs and native non-X11 runtime behavior still require
verification; CI configuration itself is not evidence of success.

One test used XDestroyWindow to close the test windows and triggered a winit
TranslateCoordinates panic. Sending the normal WM_DELETE_WINDOW protocol instead
closed the reloaded editor successfully with exit code 0. This was a test-harness
mistake, not the normal close path; originals and saved edits were unaffected.

GPU photo compute, embedded lens data, neural inference/synthesis, HDR display
presentation, and stronger color/reconstruction comparisons remain open.
