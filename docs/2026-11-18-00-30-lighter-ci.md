# Lighter CI

Pushes and pull requests now run the three-platform Rust matrix for formatting,
Clippy, debug tests, DNG fixtures, native editor smoke tests, and GPU and display
checks.

The Native learning workflow runs nightly at 09:23 UTC. Its scheduler and layer
tests share the LibTorch setup with the real-model export and inference checks,
so the whole matrix runs together. To run it on demand from the default branch,
use `gh workflow run native-learning.yml`. Add `-f legacy_raw_inference=true`
to include the legacy RawNIND integration checks.
