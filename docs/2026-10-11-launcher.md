# Launch script review

Updated the user's launcher to source `tools/libtorch-env.sh`, including the
project-owned Torch/NVIDIA loader paths. This replaces duplicated hard-coded
Torch configuration, which omitted the runtime library path.

The script resolves its repository directory and passes an absolute manifest
path to Cargo, retaining the caller's working directory for relative photo
paths. It forwards all arguments with `-- "$@"`, stops on setup failure, uses
the checked-in lockfile, and replaces its shell with Cargo. The executable
permission is retained.

Manual verification used the existing Rust 1.99 release build: `--version`
succeeded, launching from a temporary directory inspected a relative JPEG path
containing spaces, and a missing Torch installation exited before Cargo ran.
Shell syntax and whitespace checks passed. The launcher uses the caller's
selected Rust toolchain rather than pinning a machine-specific override.
