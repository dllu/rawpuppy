# RAW core, composed pipeline, and color-managed export

Implemented Rust RAW/RGB input, source immutability, versioned edit recipes,
MHC Bayer reconstruction, a sensor denoise/hot-pixel baseline, composed geometry,
scene gain and calibration, analytic AgX, clone/heal, monotone curve, split toning,
ICC-tagged integer exports, float EXR, and independent atomic XMP sidecars.
Added a CLI, a concise README, research notes, and a full-scope completion audit.

Validation: 13 integration tests cover all Bayer layouts, EXIF orientations,
100,003-pixel width, checked overflow, pinhole coordinate invariants, unbounded
scene highlights, tone invariants, retouch, XMP namespace/isolation, no-clobber
exports, HDR EXR, and ICC exports/reloads in sRGB/P3/Adobe RGB/Rec.2020.
`cargo clippy --all-targets -- -D warnings` passes.

Read two real GFX100S originals from `~/pictures/raw`; no files were written there.
One 11808×8754 sensor decoded in about 0.50 seconds and rendered a 1800-pixel
preview in 0.13 seconds before encoding. Its EXIF orientation is Rotate 270 CW.
A complete 8736×11648 16-bit TIFF export took 6.06 seconds wall time (0.42 seconds
decode, 4.57 seconds render, 0.89 seconds encoding); peak RSS was 3,343,936 KiB.
These are single runs with eight CPU workers, not controlled benchmark averages.
All outputs are under `/tmp/rawpuppy-validation`.

Found and corrected two integration pitfalls: Rawler's modern camera matrix is
in the color-matrix map, and its RAF image orientation needs the separate EXIF
metadata path. Also found that `image`'s TIFF allocation-limit adapter makes
metadata retrieval fail on tiny images because the TIFF decoder applies the
image-buffer budget to expanded metadata values. Rawpuppy reads RGB TIFF through
the `tiff` crate directly with address-space limits and independently verifies
the embedded ICC. This also avoids the decoder's default image-size cap.

Remaining work is explicit in `requirements.md`: GUI, native GPU compute,
embedded lens data, neural synthesis, stronger reconstruction/denoise evaluation,
display profile discovery, HDR presentation, and platform verification.
